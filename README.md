# ArceusTech Remote Support — sorgenti e licenze

Download gratuito dei sorgenti delle versioni distribuite di ArceusTech Remote Support, basato su RustDesk e RustDesk Server OSS. Le licenze originali, incluse AGPL-3.0 e quelle delle dipendenze, sono conservate negli archivi.

## Download

[Releases e archivi sorgenti](https://github.com/arceustechlab-code/ArceusTechRemoteSupport-Sources/releases).

La prima release `source-snapshot-2ba909e` contiene lo snapshot completo del repository del commit `2ba909e1ef8c355b0648ab034a0e1a484cba2863`, con manifest e SHA256. È uno snapshot preparatorio: le build configurate e i test remoti sono ancora da completare. I sorgenti delle dipendenze risolte e gli archivi corrispondenti ai singoli binari verranno aggiunti alle release effettive prima della distribuzione.

Le release dei binari includeranno archivi sorgenti separati per piattaforma e profilo, inventari licenze e hash. Seguire README_BUILD.md dentro l'archivio. Le versioni già distribuite restano scaricabili.

Il repository di sviluppo rimane privato. Questo canale non contiene credenziali, private key, database runtime del VPS o cronologia Git privata. Il codice, il branding e gli input pubblici necessari alla ricostruzione sono inclusi negli archivi.

Marchi e asset di terzi conservano i rispettivi titolari; non si dichiara affiliazione con RustDesk. L'identità ArceusTech/Arceustech appartiene al titolare del progetto.
